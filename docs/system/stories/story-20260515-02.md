# 使用者透過 TC 傳訊息給 Claude 並收到回應

**日期**：2026-05-15

## 互動關係

**As a** 使用者  
**I want** 在 TC 傳訊息後收到 Claude 的回應  
**So that** 我離開電腦時仍可與 Claude 協同作業

## 流程

```
使用者 → 訊息 → bot → tmux send-keys → Claude 處理 → bot 擷取 → TC 收到回應
```

## 驗收條件

- 回應正確顯示在 TC
- 長回應自動分段（每段 4000 字）
- PC 的 tmux pane 可看到相同的一來一往
