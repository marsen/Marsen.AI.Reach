# 使用者在長任務期間收到進度通知

**日期**：2026-05-15

## 互動關係

**As a** 使用者  
**I want** 傳訊息後等待期間每隔一段時間收到「還在思考中」的通知  
**So that** 我知道 Claude 還在處理，不需要擔心是否卡住

## 流程

```
使用者 → 傳訊息 → Claude 開始處理
每 30 秒 → TC 收到「⏳ 還在思考中（N 秒）...」
Claude 完成 → TC 收到正式回應
```

## 驗收條件

- 每 30 秒推送一次進度通知
- 收到正式回應後不再推送進度通知
