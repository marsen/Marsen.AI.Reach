# 使用者透過 TC 查詢 session 狀態

**日期**：2026-05-15

## 互動關係

**As a** 使用者  
**I want** 在 TC 輸入 `/status` 查詢目前 session 狀態  
**So that** 我知道是否需要重新 /start

## 流程

```
使用者 → /status → bot → 查詢狀態 → TC 收到「✅ Session 進行中」或「💤 沒有 session」
```

## 驗收條件

- 狀態正確反映實際情況（session 真的死掉時顯示 inactive，而非誤報 active）
