# 使用者透過 TC 啟動 Claude session

**日期**：2026-05-15

## 互動關係

**As a** 使用者  
**I want** 在 TC 輸入 `/start` 後 Claude session 啟動  
**So that** 我可以開始與 Claude 協同作業

## 流程

```
使用者 → /start → bot → ensure session → 回傳「🆕 新對話」或「🔄 接續對話」
```

## 驗收條件

- 新 session：TC 收到「🆕 新對話 + 工作目錄」
- 接續 session：TC 收到「🔄 接續對話 + 工作目錄」
- PC 可透過 `rai` 附掛到同一個 session 看到相同歷程
