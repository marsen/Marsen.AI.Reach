# 使用者在 PC 執行任務後，TC 收到完成通知

**日期**：2026-05-15

## 互動關係

**As a** 使用者  
**I want** 離開電腦後，Claude 在 PC 完成任務時 TC 自動通知我  
**So that** 我不需要一直盯著電腦，也能知道任務完成

## 流程

```
使用者在 PC 啟動長任務 → 離開電腦
Claude 完成 → watcher 偵測到 pane 有新輸出
→ TC 收到「📬 背景任務完成：...」
```

## 驗收條件

- 任務完成時 TC 收到通知
- 相同內容不重複推送
- bot 主動觸發的回應不觸發 watcher（避免重複）
