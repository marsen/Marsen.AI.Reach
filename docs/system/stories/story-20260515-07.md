# 使用者可切換訊息平台（Telegram / LINE）

**日期**：2026-05-15

## 互動關係

**As a** 使用者  
**I want** 能透過不同訊息平台（Telegram 或 LINE）使用相同功能  
**So that** 我可以選擇自己習慣的平台，系統不綁定單一服務

## 流程

```
設定 PLATFORM=telegram 或 PLATFORM=line → 重啟 bot
→ 相同的 /start、/stop、/status、傳訊息、通知功能正常運作
```

## 驗收條件

- 切換平台後所有功能行為一致
- 新平台只需實作 Platform Adapter 介面，不需修改核心邏輯
